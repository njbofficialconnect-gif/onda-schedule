# ONDA 통합 일정관리

박현기(대표) · 변시원(전무이사) · 박현우(부대표) 3명이 함께 보는 온다(ONDA) 통합 캘린더입니다.

한 화면에서 다음 일정을 색깔로 구분해서 보여줍니다.
- 유튜브 업로드 일정
- 박현기 대표 / 변시원 전무이사 / 박현우 부대표 개인 일정 (시간·장소·기간·지출·세부사항)
- ONDA 행사 일정
- 회의 / 미팅
- 계약서 작성일

일정을 클릭하면 세부내용을 바로 수정할 수 있고, 상대방(거래처/게스트)의 회사명·이름·직책·이메일을
등록해두면 그 자리에서 `njb.official.connect@gmail.com` 계정으로 바로 메일을 보낼 수 있습니다.
보낸 메일은 발송 기록으로 남아 3명 모두 확인할 수 있습니다.

추가로 이런 기능도 있습니다.
- **카카오톡 알림**: 각자 카카오 계정을 연동해두면, 본인 담당 일정의 하루전/1시간전 알림이
  카카오톡 "나에게 보내기"로 옵니다.
- **홈 화면에 앱처럼 설치 (PWA)**: 휴대폰 브라우저에서 "홈 화면에 추가"하면 아이콘이 생기고
  앱처럼 실행됩니다. 스토어 등록 없이 지금 바로 쓸 수 있습니다.
- **엑셀 내보내기**: 사이드바의 "엑셀로 내보내기"에서 기간/종류를 골라 다운로드하거나,
  이메일 주소를 입력해 바로 첨부파일로 보낼 수 있습니다.

## 1. 처음 설치하기

```bash
cd onda-schedule
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

`.env.example`을 복사해서 `.env` 파일을 만들고 값을 채워주세요.

```bash
copy .env.example .env
```

- `FLASK_SECRET_KEY`: 아무 긴 임의의 문자열
- `GMAIL_APP_PASSWORD`: `.env.example` 안의 설명을 따라 구글 "앱 비밀번호"를 발급받아 입력
  (이걸 설정하지 않아도 캘린더는 정상 작동하고, 메일 발송 버튼만 비활성화됩니다)
- `KAKAO_REST_API_KEY` / `KAKAO_REDIRECT_URI`: 카카오톡 알림을 쓰려면 채워주세요.
  자세한 절차는 `.env.example` 안의 설명을 그대로 따라하면 됩니다 (카카오 개발자센터에서
  앱 만들고, 카카오 로그인 켜고, "카카오톡 메시지 전송" 동의항목 신청, 팀원에 3명 등록).
  설정하지 않아도 캘린더는 정상 작동하고, 카카오 알림 기능만 꺼진 채로 동작합니다.
- `APP_BASE_URL`: 실제 배포한 주소가 있다면 그 주소로 바꿔주세요. 로컬에서만 쓸 땐 그대로 두면 됩니다.

## 2. 계정 만들기 + 기존 일정표 불러오기

```bash
python seed.py
```

- 박현기 / 변시원 / 박현우 3명의 로그인 계정을 자동으로 만듭니다. **임시 비밀번호가 터미널에
  한 번만 출력**되니 꼭 캡처하거나 적어두세요. 로그인 후 우측 상단 [비밀번호 변경]에서 각자
  원하는 비밀번호로 바꾸시면 됩니다.
- `Desktop/ONDA/온다_통합일정표.xlsx`에 정리되어 있던 2026년 9~11월 유튜브 업로드/미팅/행사
  일정을 자동으로 캘린더에 넣어줍니다. 이후 12월~2월 일정은 앱에서 직접 추가하시면 됩니다.

이 스크립트는 다시 실행해도 안전합니다 (이미 있는 계정/일정은 중복으로 만들지 않습니다).

## 3. 실행하기

```bash
python app.py
```

브라우저에서 http://127.0.0.1:5050 접속 후 로그인하세요.

## 4. 사용법 요약

- **새 일정 추가**: 좌측 상단 버튼 또는 달력 날짜 클릭
- **일정 종류 필터**: 좌측 사이드바 체크박스로 원하는 종류만 켜고 끌 수 있습니다
- **기간이 있는 일정**: 시작일/종료일을 다르게 입력하면 달력에 자동으로 여러 날에 걸쳐 표시됩니다
- **지출**: 대표/전무이사/부대표 개인 일정뿐 아니라 모든 일정에 지출 금액과 메모를 남길 수 있습니다
- **이메일 보내기**: 일정 상세 안에 담당자 연락처(회사명/이름/직책/이메일)를 입력하면
  "이 연락처로 이메일 보내기" 버튼이 활성화됩니다. 제목/내용을 확인하고 발송하면
  `njb.official.connect@gmail.com`으로 실제 발송되고, 발송 기록이 해당 일정 안에 남습니다.
- **카카오톡 알림 연동**: 우측 상단 [비밀번호 변경] 페이지에 "카카오톡 알림 연동하기" 버튼이
  있습니다. 각자 자기 계정으로 한 번만 눌러서 연동하면, 그 다음부터 본인 담당 일정(대표/전무이사/
  부대표 개인 일정)의 하루전/1시간전에 카카오톡 "나에게 보내기"로 알림이 옵니다. 담당자가
  지정 안 된 일정(유튜브 업로드/행사/회의/계약서)은 연동한 사람 모두에게 알림이 갑니다.
  서버가 켜져 있는 동안 5분마다 확인해서 보내며, 시작 시간을 안 정한 일정은 오전 9시 기준으로
  계산합니다.
- **엑셀 내보내기**: 사이드바 "엑셀로 내보내기" 클릭 → 시작일/종료일(선택)을 고르면 좌측에서
  체크한 종류만 담아 엑셀로 만들어줍니다. "다운로드"로 바로 받거나, 이메일 주소를 입력하고
  "이메일로 보내기"를 누르면 `njb.official.connect@gmail.com`으로 즉시 첨부파일 발송됩니다
  (Gmail 앱 비밀번호 설정 필요).

## 5. 휴대폰에 앱처럼 설치하기 (PWA)

별도 스토어 설치 없이, 배포한 주소로 휴대폰 브라우저에서 접속한 뒤:
- **아이폰(Safari)**: 공유 버튼 → "홈 화면에 추가"
- **안드로이드(Chrome)**: 우측 상단 점 3개 메뉴 → "홈 화면에 추가" 또는 "앱 설치"

홈 화면에 ONDA 아이콘이 생기고, 탭하면 주소창 없이 앱처럼 전체화면으로 실행됩니다.
(localhost가 아닌 실제 도메인으로 배포할 때는 HTTPS가 필요합니다 — 아래 5-1 참고.)

## 6. 배포하기 (Render + Neon)

테니스토리 프로젝트와 같은 방식(Render.com + PostgreSQL)으로 배포합니다. 로컬의 SQLite
파일은 서버가 재시작될 때마다 초기화되는 호스팅이 많아서, 등록한 일정이 사라지지 않도록
처음부터 영구 저장되는 PostgreSQL을 씁니다.

### 6-1. GitHub에 올리기

이 폴더는 이미 git 저장소로 초기화되어 있고 첫 커밋도 되어 있습니다. GitHub에
`onda-schedule`이라는 이름으로 빈 저장소를 하나 만든 뒤(https://github.com/new,
"Initialize with README" 체크 해제) 아래처럼 연결해서 올리면 됩니다.

```bash
git remote add origin https://github.com/njbofficialconnect-gif/onda-schedule.git
git push -u origin main
```

### 6-2. 무료 PostgreSQL 만들기 (Neon)

1. [neon.tech](https://neon.tech) 가입 → 프로젝트 생성 (이름 예: onda)
2. 생성되면 보여주는 **Connection string**을 복사 (`postgresql://...` 형태)
   — 이게 `DATABASE_URL`에 넣을 값입니다.

(Supabase의 PostgreSQL을 대신 써도 됩니다 — 테니스토리 README에 있는 것과 동일한 방식)

### 6-3. Render에 배포하기

1. [render.com](https://render.com) 가입/로그인 (테니스토리와 같은 계정이면 그대로 사용)
2. **New > Web Service** → 위에서 올린 `onda-schedule` GitHub 저장소 선택
3. 설정:
   - **Runtime**: Python 3
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `gunicorn app:app`
4. **Environment** 탭에서 아래 값들을 추가:

   | 키 | 값 |
   |---|---|
   | `DATABASE_URL` | 6-2에서 복사한 Neon connection string |
   | `FLASK_SECRET_KEY` | 아무 긴 임의의 문자열 |
   | `GMAIL_ADDRESS` | `njb.official.connect@gmail.com` |
   | `GMAIL_APP_PASSWORD` | 발급받은 구글 앱 비밀번호 |
   | `APP_BASE_URL` | 배포되면 알려주는 주소 (예: `https://onda-schedule.onrender.com`) |
   | `KAKAO_REST_API_KEY` | 카카오 개발자센터에서 발급받은 키 (안 쓰면 생략 가능) |
   | `KAKAO_REDIRECT_URI` | `{APP_BASE_URL}/kakao/callback` |

   `APP_BASE_URL`은 배포가 한 번 끝나서 실제 주소를 알게 된 뒤에 채우고, 저장하면
   Render가 자동으로 재배포합니다.
5. **Create Web Service** → 몇 분 후 배포 완료, 주소로 접속하면 로그인 화면이 뜹니다.

### 6-4. 계정 만들기 + 초기 일정 넣기 (배포된 DB에 한 번만)

Render 대시보드의 해당 서비스 → **Shell** 탭을 열고 아래 명령 한 번만 실행합니다.

```bash
python seed.py
```

로컬에서 했던 것과 똑같이 3명의 로그인 계정과 초기 일정이 만들어집니다. 임시
비밀번호가 여기서도 한 번만 출력되니 꼭 적어두세요.

### 6-5. 카카오/휴대폰 설치 마무리

- 카카오톡 알림을 쓴다면, 카카오 개발자센터의 Redirect URI에
  `https://onda-schedule.onrender.com/kakao/callback`(배포 주소 기준)을 추가로 등록하세요.
- Render는 기본으로 HTTPS를 제공하므로, 배포 주소로 휴대폰에서 접속해 "홈 화면에 추가"하면
  바로 PWA로 설치됩니다 (위 5번 참고).
- Render 무료 플랜은 일정 시간 요청이 없으면 슬립 상태가 되어 첫 접속이 느릴 수 있습니다.
  계속 켜져 있어야 한다면 유료 플랜(Starter 등)으로 올리는 걸 권장합니다.
